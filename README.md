# Nightfall

An interactive ASCII moon and star field. Buildless HTML, CSS, and JavaScript; no runtime dependencies.

Run `npm run dev` and open http://localhost:5173. Run `npm run check` to check JavaScript syntax.

The canvas renders at a capped 30fps and 2x pixel density. Moon phase, star density, pause/resume, an about dialog, and an immersive sky view are keyboard accessible. Reduced-motion preferences pause the initial scene. The sky is illustrative rather than astronomical.
