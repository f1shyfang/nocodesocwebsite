# No Code Society (NCS)

A minimal No Code Society page with the supplied logo, dark header, and accessible about dialog. A drifting ASCII rendering of the supplied No Code Society crescent logo (including its central lettering) and star field fills the page, with no sky controls or hero copy. The footer reads 'nocodesociety 2026'. Motion respects reduced-motion preferences and stops in hidden tabs.

Run `npm run dev` and open http://localhost:5173. Run `npm run check` to check JavaScript syntax. Buildless HTML, CSS, and JavaScript; no runtime dependencies.
